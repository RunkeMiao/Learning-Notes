# JavaSE 笔记（一）：走进 Java 语言

> 这份笔记把“计算机如何运行程序”和“Java 如何开始运行”连起来讲。第一次学习时先理解整体流程，不必急着记住所有术语；后面写代码时再回来查阅。

## 先看这张路线图

```text
人编写 Java 源代码（.java）
          ↓ javac 编译
Java 字节码（.class）
          ↓ JVM 加载、解释或即时编译
操作系统与 CPU 执行
```

关键点：`.java` 是我们编写的代码，`.class` 是 Java 虚拟机能读取的字节码；JVM 会把字节码变成当前机器能执行的指令。不同系统需要对应平台的 JVM，因此同一份 Java 字节码通常能在多个平台运行。

## 1. 学 Java 前先认识计算机

### 1.1 计算机由什么组成？

计算机最终由电路构成。电路可以区分两种状态，常用 `0` 和 `1` 表示。这里的 0、1 是二进制数位，也常被用来表示“假/真”或“低电平/高电平”。真实硬件的电压范围和信号判定比这个比喻更复杂，初学阶段先这样理解即可。

二进制只有 `0`、`1` 两个数字，规则是“逢二进一”：

- 十进制：`9 + 1 = 10`
- 二进制：`1 + 1 = 10`（读作“一零”，表示十进制的 2）

数字电路中的逻辑门可以组合出运算和判断。最基本的逻辑有：

| 逻辑 | 含义 | 示例 |
|---|---|---|
| 与（AND） | 两边都为真，结果才为真 | `1 & 1 = 1`；`1 & 0 = 0` |
| 或（OR） | 至少一边为真，结果就为真 | `1 \| 0 = 1`；`0 \| 0 = 0` |
| 非（NOT） | 把真假反过来 | `!1 = 0`；`!0 = 1` |

> 上表中的符号用于帮助理解逻辑。Java 代码里 `&`、`|`、`!` 的具体用法还要结合数据类型和运算规则学习。

### 1.2 计算机的主要部件

常见的计算机结构可以概括成五类：

- **运算器**：进行算术和逻辑运算。
- **控制器**：安排指令按顺序执行，协调其他部件。运算器和控制器通常集成在 CPU 中。
- **存储器**：保存数据和程序。内存速度快，主要保存正在运行时要用的内容；硬盘、固态硬盘等外存容量较大，主要长期保存文件。
- **输入设备**：把信息送进电脑，例如键盘、鼠标、麦克风。
- **输出设备**：把处理结果呈现出来，例如显示器、扬声器、打印机。

**容易混淆：** 手机宣传的“256 GB”通常指存储空间（外存）；“8 GB 运行内存”指 RAM。内存和外存用途不同，不能把它们都叫成一回事。

CPU 像负责执行工作的核心，内存像临时工作台，硬盘像长期文件柜。这个比喻有助于入门，但它不代表计算机内部真的按人的思路工作。

### 1.3 操作系统做什么？

**操作系统（Operating System，OS）** 管理计算机硬件和软件资源，并提供人和程序使用计算机的方式。常见操作系统有 Windows、macOS、Linux，以及手机上的 Android、iOS。

操作系统会处理很多基础工作，例如：

- 管理内存、文件和设备；
- 安排程序运行并分配 CPU 时间；
- 提供图形界面或命令行，让人操作电脑；
- 为应用程序提供使用硬件的接口。

没有操作系统，硬件仍然存在，但运行普通应用、管理文件和与用户交互都会困难得多。Linux 有许多发行版，有些带桌面界面，有些主要通过命令行操作；学习 Java 时会逐渐接触 Linux。

**命令行**就是通过输入文字命令操作电脑的界面。在 Windows 上常见的是 CMD 或 PowerShell，在 macOS 和 Linux 上常见的是终端。之后的 `cd`、`java`、`javac` 都是命令行命令。

### 1.4 程序和编程语言是什么？

CPU 按照指令工作。把一组指令按顺序组织起来，让计算机完成任务，就是程序。CPU 能直接执行的是与它的指令集和平台相匹配的机器指令；机器指令通常以二进制形式表示。

直接写二进制既难读也难维护，于是出现了不同层次的编程语言：

1. **机器语言**：直接对应机器指令，人很难阅读。
2. **汇编语言**：用 `MOV`、`PUSH` 之类的助记符表示机器指令，仍然贴近硬件。
3. **高级语言**：用更接近人类表达的语法描述任务，例如 C、Java、Python。编译器或解释器等工具负责把代码转成计算机能执行的形式。

例如，下面的 C 代码表达“把两个数相加”：

```c
int a = 10;
int b = 10;
int c = a + b;
```

语言语法看起来更容易理解，但程序最终仍要经过工具处理，才能在计算机上运行。**编译器**是把一种程序表示转换成另一种表示的工具；具体过程可能还包括链接等步骤。

## 2. Java 是怎样运行的？

### 2.1 编译型和解释型的简单区别

- **编译**：先把源代码转换成另一种可执行形式，再运行。很多本地程序会编译成与特定操作系统、CPU 架构相匹配的机器码。
- **解释执行**：由运行时程序读取代码或中间表示，并一步步执行。

这两个词是概括性的分类。现代语言运行时常把编译和解释结合起来，因此不必把所有语言硬分成互不相干的两类。

### 2.2 Java 的运行流程

Java 既有编译步骤，也有运行时处理步骤：

1. 程序员编写 `.java` 源文件。
2. Java 编译器 `javac` 把源文件编译成 `.class` 字节码。
3. JVM 加载并执行字节码。它可以解释执行，也可能通过即时编译（JIT）把常用部分编译成机器码。
4. 操作系统和 CPU 配合完成实际工作。

所以，说 Java“既编译又解释”是入门时常用的简化说法。更准确地说：**Java 源码先编译为字节码，JVM 再通过解释和/或即时编译执行字节码。**

### 2.3 JVM、JRE、JDK 分别是什么？

- **JVM（Java Virtual Machine，Java 虚拟机）**：运行 Java 字节码的虚拟机。不同操作系统有对应的 JVM 实现。
- **JRE（Java Runtime Environment，Java 运行环境）**：传统上指运行 Java 程序所需的 JVM 和相关运行组件。
- **JDK（Java Development Kit，Java 开发工具包）**：开发 Java 程序所需的工具集合，包含编译器等工具，也包含运行 Java 程序所需的组件。

可以先记成：**只运行程序需要运行环境；开发程序用 JDK。** 新版本 Java 的发行和安装方式有所变化，很多 JDK 发行版不再单独提供传统意义上的 JRE 安装包；学习时安装一个合适的 JDK 即可。

### 2.4 Java 为什么能跨平台？

Java 的常用口号是 **Write Once, Run Anywhere**，即“一次编写，到处运行”。它的关键是：Java 源码编译出的字节码不直接绑定某一种 CPU 指令集；只要目标系统有兼容的 JVM，JVM 就能负责执行。

```text
同一份 .class 字节码
        ├── Windows 上的 JVM
        ├── macOS 上的 JVM
        └── Linux 上的 JVM
```

这并不意味着任何 Java 程序在任何设备上都一定能原样运行。程序如果依赖特定操作系统、硬件、文件路径或本地库，仍可能需要调整；JDK、JVM 版本也要兼容。

### 2.5 Java 常见应用与版本系列

Java 曾广泛用于服务器、企业软件、Android 应用和桌面程序等领域。技术生态会随时间变化，具体项目选择什么语言和版本要看实际需求。

传统上常把 Java 平台分为：

- **Java SE（Standard Edition）**：Java 的标准基础平台，是学习语法、面向对象、集合、输入输出等内容的起点。
- **Java EE（Enterprise Edition）**：面向企业应用的规范体系；后来演进为 Jakarta EE。学习企业后端时会接触相关框架和技术。
- **Java ME（Micro Edition）**：面向资源受限设备的 Java 平台，现今的使用场景相对有限。

本系列先学习 JavaSE。先把基础概念、语法和编程习惯学扎实，再进入更大的应用开发内容。

## 3. 安装 Java 开发环境

> 安装界面和下载页面会随着版本更新而变化。下面记住判断方法和验证命令即可；如果教程截图与当前页面略有不同，以所选 JDK 发行版当前提供的安装说明为准。

### 3.1 选择并安装 JDK

JDK 有多个发行版，例如 Oracle JDK、Eclipse Temurin、Azul Zulu 等。初学者选择一个可信、适合自己操作系统的发行版即可。下载时确认：

- 操作系统是否正确（Windows、macOS 或 Linux）；
- CPU 架构是否正确（如 x64 或 ARM64）；
- 版本是否符合课程和 IDE 的支持要求；
- 安装包类型是否适合自己。

安装路径建议使用英文和数字，避免空格、特殊字符或中文引发某些工具兼容问题。是否安装到默认目录可按自己的环境决定；如果改了路径，后续配置 JDK 时记得选择正确位置。安装向导若提供设置 `JAVA_HOME` 或更新 `PATH` 的选项，可以按提示配置。

- `JAVA_HOME`：常用环境变量，指向 JDK 安装目录。
- `PATH`：系统查找命令的路径列表。把 JDK 的命令目录加入 `PATH` 后，终端就能直接找到 `java` 和 `javac`。

### 3.2 验证安装是否成功

打开一个新的终端窗口，运行：

```text
java --version
javac --version
```

两条命令都能显示版本信息，通常表示运行工具和编译工具都可以从命令行使用。如果提示“不是内部或外部命令”或“找不到命令”，检查 JDK 是否安装成功、`PATH` 是否配置正确；修改环境变量后要重新打开终端，有时需要重新登录或重启。

### 3.3 手动编译并运行第一个 Java 程序

新建一个名为 `Main.java` 的文件，注意文件名和大小写：

```java
public class Main {
    public static void main(String[] args) {
        System.out.println("Hello World!");
    }
}
```

先进入文件所在目录，再执行：

```text
javac Main.java
java Main
```

编译成功后通常会在目录中看到 `Main.class`。运行时写 `java Main`，**不要加 `.class` 后缀**。预期输出：

```text
Hello World!
```

此刻先知道这段程序可以运行即可。后面会逐步解释 `class`、`main`、`String[] args` 和 `System.out.println`。

## 4. 使用 IntelliJ IDEA 编写 Java

### 4.1 IDE 是什么？

**IDE（Integrated Development Environment，集成开发环境）**把编辑器、代码提示、错误检查、编译运行等常用功能放在一个软件里。IntelliJ IDEA 是常用的 Java IDE。社区版可以满足很多 JavaSE 入门学习需求；具体功能和授权方式以 JetBrains 当前说明为准。

下载 IDE 时，检查它是否支持你安装的 JDK 版本。新版本 JDK 通常需要相对较新的 IDE。不要只看某个旧教程里的版本号。

### 4.2 创建并运行项目

IDEA 以“项目”管理代码。创建 Java 项目时，通常要选择：

- **项目名称和位置**：用容易辨认的名称；路径尽量简单，避免特殊字符。
- **构建系统**：刚开始可用 IDE 自带的简单项目配置；以后课程需要时再学 Maven 或 Gradle。
- **JDK**：选择已经安装的 JDK。找不到时，通过 IDE 设置 JDK 安装目录。
- **示例代码**：如果 IDE 提供示例代码，可以先保留，方便确认环境是否可运行。

创建后，在 `src` 等源码目录中打开或新建 Java 类。点击代码旁边的运行按钮，IDE 通常会自动编译并运行，然后在下方控制台显示输出。IDE 生成的编译结果通常位于项目配置的输出目录中；具体目录因项目设置而异。

如果代码突然标红，先确认 IDE 正在加载项目、索引已经完成，并且项目选择了正确的 JDK。还可以看底部运行窗口或错误提示，按具体信息排查。

**IDEA 是工具，不是 Java 本身。**以后换到别的编辑器，只要 JDK 和项目配置正确，Java 程序依然可以编译运行。

## 5. 初学者容易混淆的概念

| 概念 | 一句话记忆 |
|---|---|
| CPU | 按指令进行运算和控制的核心硬件 |
| 内存（RAM） | 程序运行时常用的临时工作空间 |
| 外存 | 长期保存文件和程序的存储空间，如 SSD、硬盘 |
| 操作系统 | 管理硬件和软件资源、提供程序运行环境的系统软件 |
| 源代码 | 程序员编写、供人阅读的代码，例如 `Main.java` |
| 编译器 | 把程序从一种表示转换成另一种表示的工具，例如 `javac` |
| 字节码 | Java 编译后生成、供 JVM 读取的 `.class` 内容 |
| JVM | 加载并执行 Java 字节码的虚拟机 |
| JDK | 开发 Java 程序所需的工具和运行组件 |
| IDE | 集成编辑、提示、编译、运行等功能的开发软件 |

## 7. 最小练习

1. 按上面的步骤创建并运行 `Main.java`。
2. 把输出文字改成自己的名字或一句话，再运行一次。
3. 分别运行 `java --version` 和 `javac --version`，观察它们显示的信息。
4. 用自己的话写下 `.java → .class → JVM` 这条流程。
