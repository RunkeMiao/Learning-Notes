# JavaSE 笔记（二）：面向过程编程

> **面向过程**可以先理解为：把要做的事情拆成一步一步的指令，再按顺序、条件和重复规则执行。本篇从 Java 程序骨架开始，学习变量、数据类型、运算符和流程控制。类和对象会在后续章节展开。

## 本篇学习路线

```text
程序骨架与注释
    ↓
变量、常量、数据类型
```

## 1. 一个 Java 程序长什么样？

```java
public class Main {
    public static void main(String[] args) {
        System.out.println("Hello World!");
    }
}
```

先把它看成初学阶段的固定模板：

- `public class Main`：声明一个叫 `Main` 的类。此处先记住：文件名为 `Main.java` 时，公开类名也写 `Main`，大小写要一致。
- `main` 方法：程序从这里开始执行。
- `System.out.println(...)`：把括号中的内容打印到控制台，并换行。
- `{}`：把一组代码括起来。花括号要成对出现。
- `;`：表示一条语句结束。换行只是排版，不能替代分号。

Java 区分大小写，`Main`、`main` 和 `MAIN` 是不同的写法。少分号、括号不配对或名称拼错，都可能导致编译失败。IDEA 通常会用错误提示帮助定位。

多条语句按从上到下的顺序执行：

```java
System.out.println("第一行");
System.out.println("第二行");
```

### 注释：写给人看的说明

注释不会作为普通程序语句执行，适合解释“为什么这么写”。

```java
// 单行注释：从 // 到本行结束

/*
 多行注释：可以跨越多行
*/

/**
 * 文档注释：常用于类、方法等说明，可供文档工具读取
 */
```

现代 Java 还有 `///` 文档注释写法，但初学时掌握上面三种即可；是否使用较新的注释形式取决于 JDK 和工具支持。

## 2. 变量和常量

### 2.1 变量像贴了标签的储物格

变量用一个名字保存某个值，程序之后可以读取或修改它。想象一个贴有标签的格子：标签是变量名，格子里的内容是变量值。

声明格式：

```java
数据类型 变量名;
```

声明并赋初值通常写在一起：

```java
int age = 18;
System.out.println(age); // 输出变量当前保存的值
age = 19;                // 修改变量的值
```

这里 `int` 是数据类型，`age` 是变量名，`=` 是赋值符号。注意：程序里的 `age = age + 1` 表示“先取出 age，加 1，再把结果存回 age”，不是在解数学方程。

```java
int a = 10;
int b = a;       // 把 a 当前保存的值复制给 b
int count;       // 只声明
count = 0;       // 之后再赋值
```

局部变量在第一次使用前必须先获得值，否则编译器会报错。字段等其他变量有不同的默认值规则，后续学习类时再了解。

同一行可以声明多个同类型变量，例如 `int a = 1, b = 2;`。初学时一行一个变量通常更清楚。

### 2.2 命名规则和习惯

变量名是**标识符**。简单记这些规则：

- 可以使用字母、数字、下划线 `_`、美元符号 `$`，但不能以数字开头；Java 标识符也支持许多 Unicode 字符。
- 不能有空格，也不能把 `+`、`-` 等运算符当作名字的一部分。
- 不能使用 Java 关键字，例如 `class`、`int`、`if`。
- `true`、`false`、`null` 是字面量，不能当作普通标识符使用。
- 大小写敏感，所以 `score` 和 `Score` 是两个不同名字。
- 使用能说明用途的名字；变量通常采用小写开头的驼峰写法，例如 `studentName`、`totalScore`。

不必死背完整关键字表；写代码时 IDE 通常会高亮关键字并提示语法错误。

### 2.3 常量：不再改变的值

在变量声明前加 `final`，表示赋值之后不能再次修改：

```java
final int DAYS_IN_WEEK = 7;
// DAYS_IN_WEEK = 8; // 错误：final 变量不能再次赋值
```

`final` 变量可以先声明、后赋值，但必须在使用前完成赋值，且只能赋值一次。常量名常用全大写加下划线，便于识别。

## 3. 数据类型：值应该怎样保存？

Java 是静态类型语言：声明变量时需要确定它保存哪类值。基本数据类型有八种。

### 3.1 八种基本类型速查

| 类别 | 类型 | 大小 | 典型用途与范围 |
|---|---|---:|---|
| 整数 | `byte` | 8 位 | -128 到 127 |
| 整数 | `short` | 16 位 | -32,768 到 32,767 |
| 整数 | `int` | 32 位 | 常用整数；约 -21 亿到 21 亿 |
| 整数 | `long` | 64 位 | 超过 `int` 范围的整数 |
| 小数 | `float` | 32 位 | 较低精度浮点数 |
| 小数 | `double` | 64 位 | 常用浮点数，精度高于 `float` |
| 字符 | `char` | 16 位 | 一个 UTF-16 代码单元，范围 0 到 65,535 |
| 真假 | `boolean` | 由 JVM 实现决定 | 只有 `true` 或 `false` |

日常计算通常优先使用 `int` 表示整数、`double` 表示小数。`byte`、`short` 多用于特定数据格式或 API；`long` 用于更大的整数。

### 3.2 二进制、位和补码

计算机用二进制表示数据。一个二进制位叫 **bit（位）**，8 bit 等于 1 **Byte（字节）**。大小写很重要：`b` 常表示 bit，`B` 表示 Byte；因此 `100 Mb/s` 理论上约等于 `12.5 MB/s`，实际下载速度还受网络开销等影响。

二进制逢二进一：`111₂ = 7₁₀`，因为 `4 + 2 + 1 = 7`。Java 的有符号整数使用**补码**表示；入门时记住范围公式即可：n 位有符号整数的范围是 `-2^(n-1)` 到 `2^(n-1)-1`。例如 8 位 `byte` 的范围是 -128 到 127。

不用在这一阶段手算所有补码细节。后面做位运算时，再回来看每一位如何参与计算。

### 3.3 整数、字面量和类型转换

直接写在代码里的整数通常按 `int` 处理；需要表示 `long` 时，在数字末尾加 `L`（推荐大写，避免和数字 1 混淆）：

```java
int population = 1_000_000;
long distance = 3_000_000_000L;
```

数字中可以用下划线分组，增强可读性，例如 `1_000_000`，下划线不会改变数值。整数常量也可用不同进制：`0b` 开头表示二进制，`0` 开头表示八进制，`0x` 开头表示十六进制。

较小范围的常量在赋值时有特例，例如 `byte b = 10;` 可以通过编译，因为 10 能放进 `byte`。但变量之间赋值仍要遵守类型规则。

从较小范围转到较大范围通常可以自动转换（**拓宽转换**），例如：

```java
short small = 10;
int larger = small;
```

把较大类型转换成较小类型叫**窄化转换**，可能丢失数据，需要显式写出：

```java
int number = 130;
byte narrowed = (byte) number; // 超出 byte 范围，结果会发生变化
```

强制转换不等于“安全转换”，使用前要确认数值不会超出目标类型范围。整数类型混合计算时，`byte`、`short`、`char` 通常先提升为 `int`；出现 `long` 时结果通常为 `long`。

### 3.4 浮点数：能表示小数，但不总是精确

小数常量默认是 `double`。`float` 常量要在末尾加 `F`：

```java
double price = 19.99;
float ratio = 0.5F;
```

浮点数使用有限位数近似表示实数，因此有些十进制小数无法精确表示。例如：

```java
double result = 0.1 + 0.2;
System.out.println(result); // 可能显示接近 0.3 的数，而不是精确的 0.3
```

需要精确进行金额等十进制计算时，不要直接依赖 `float` 或 `double`；后续可学习 `BigDecimal`。普通科学计算和测量常会使用浮点数，并接受其精度特性。

### 3.5 字符、字符串与 Unicode

`char` 用单引号表示一个字符：

```java
char initial = 'A';
char chinese = '中';
```

`char` 表示一个 UTF-16 代码单元，不是任意可见字符都必然只占一个 `char`；例如某些 emoji 需要两个代码单元。理解字符串和 Unicode 时再深入即可。

`String` 表示一串文字，用双引号：

```java
String message = "你好，Java";
```

`String` 不是八种基本类型之一，而是 Java 的类类型，之后面向对象章节会详细学习。这里先会创建和打印字符串即可。

**字符集与编码：** Unicode 为字符分配编号；UTF-8、UTF-16 是把字符表示为字节或代码单元的编码方式。不要把“有哪些字符”与“如何编码保存”混成一件事。Java 源文件常用 UTF-8 保存，但这不代表每个字符在所有场景都只占一个字节。

### 3.6 布尔值：条件判断的结果

`boolean` 只有两个值：

```java
boolean isReady = true;
boolean hasError = false;
```

Java 条件必须是 `boolean`，不能像 C 语言那样直接把整数当作真假。

### 3.7 `var`：让编译器推断局部变量类型

Java 10 起，可以在有初始值的局部变量声明中使用 `var`：

```java
var count = 10;       // 推断为 int
var title = "入门";   // 推断为 String
```

`var` 不是“类型可以随时变化”，变量的类型仍然固定；也不能只写 `var count;` 而不提供初始值。初学时显式写 `int`、`String` 更利于理解类型，类型很明显时再考虑 `var`。

## 4. 运算符：让值参与计算

### 4.1 赋值与算术运算

常见算术运算符：`+`、`-`、`*`、`/`、`%`。`%` 求余数。

```java
int sum = 10 + 3;       // 13
int quotient = 8 / 5;   // 1：整数除法会丢掉小数部分
int remainder = 8 % 5; // 3
```

如果希望得到小数，确保至少一边在运算前是小数类型：

```java
double quotient = 8.0 / 5; // 1.6
```

`(double) (8 / 5)` 仍然先做整数除法得到 1，再转成 `1.0`；转换要放在除法之前才会影响计算。

加号也可以拼接字符串：

```java
String text = "分数：" + 95; // "分数：95"
```

计算顺序大体遵循数学规则；遇到不确定的优先级时，加括号让意图清楚。

### 4.2 自增、自减和复合赋值

```java
int count = 8;
count++;  // count 变成 9
count--;  // count 又变成 8
count += 4; // 等价于 count = count + 4
count *= 2; // 等价于 count = count * 2
```

`++count` 和 `count++` 单独作为语句时，最终都让变量加 1；放进更大的表达式时结果不同：

```java
int a = 8;
int before = a++; // before 得到旧值 8，然后 a 变为 9
int after = ++a;  // a 先变为 10，然后 after 得到 10
```

初学时避免在同一个表达式里多次修改同一变量，例如 `-a++ + ++a`。拆成多行更容易看懂，也更不容易出错。

### 4.3 比较和逻辑运算

比较运算得到 `boolean`：

| 运算符 | 含义 |
|---|---|
| `>`、`<` | 大于、小于 |
| `>=`、`<=` | 大于等于、小于等于 |
| `==`、`!=` | 相等、不相等 |

一个等号 `=` 是赋值，两个等号 `==` 是比较：

```java
int score = 85;
boolean passed = score >= 60;
```

用逻辑运算把条件组合起来：

- `&&`：并且，两边都为 `true` 才为真；有短路特性，左边为 `false` 时右边不再计算。
- `||`：或者，至少一边为 `true` 就为真；左边为 `true` 时右边不再计算。
- `!`：取反，把 `true` 变 `false`，反之亦然。

例如判断分数是否在 60 到 100 之间：

```java
boolean validScore = score >= 60 && score <= 100;
```

Java 里不能写数学式 `60 <= score <= 100`，因为前半段 `60 <= score` 已经算出真假值了。

### 4.4 三元运算符

三元运算符根据条件在两个结果中选一个：

```java
条件 ? 条件为真时的值 : 条件为假时的值
```

```java
int score = 85;
String result = score >= 60 ? "及格" : "未及格";
```

它适合简单的二选一。条件复杂或两边要执行多条语句时，使用 `if-else` 更清楚。

### 4.5 运算符优先级速查

优先级决定一个表达式里“先算谁”。下表按**从高到低**排列，同一行的运算符通常按从左到右结合；赋值和三元运算符按从右到左结合。这里只列当前阶段常用的运算符：

| 优先级（高 → 低） | 运算符 | 说明 |
|---:|---|---|
| 1 | `()` | 括号内优先计算 |
| 2 | `!`、`~`、一元 `+` / `-`、`++` / `--`、类型转换 `(类型)` | 一元运算 |
| 3 | `*`、`/`、`%` | 乘、除、取余 |
| 4 | `+`、`-` | 加、减；`+` 也可拼接字符串 |
| 5 | `<<`、`>>`、`>>>` | 位移 |
| 6 | `<`、`<=`、`>`、`>=`、`instanceof` | 大小比较、类型判断 |
| 7 | `==`、`!=` | 相等、不相等 |
| 8 | `&` | 按位与；用于 `boolean` 时也表示非短路与 |
| 9 | `^` | 按位异或；用于 `boolean` 时表示非短路异或 |
| 10 | `|` | 按位或；用于 `boolean` 时也表示非短路或 |
| 11 | `&&` | 短路与 |
| 12 | `||` | 短路或 |
| 13 | `?:` | 三元条件运算符 |
| 14 | `=`、`+=`、`-=`、`*=`、`/=`、`%=` 等 | 赋值，按从右向左结合 |

例如：

```java
int result = 2 + 3 * 4;    // 先乘后加，结果是 14
int clear = (2 + 3) * 4;  // 括号改变顺序，结果是 20
int a, b;
a = b = 5;                 // 赋值从右向左：先 b = 5，再 a = 5
```

**实用记法：** 括号可以明确表达你的意图。尤其是同时出现比较、逻辑运算或多个自增自减时，优先加括号或拆成多行，不必靠死记优先级来猜代码。

### 4.6 位运算（了解即可）

位运算直接对整数的二进制位进行操作，初学先掌握名称和基本效果：

| 运算符 | 名称 | 每一位的规则 |
|---|---|---|
| `&` | 按位与 | 两位都为 1，结果才为 1 |
| `|` | 按位或 | 至少一位为 1，结果为 1 |
| `^` | 按位异或 | 两位不同，结果为 1 |
| `~` | 按位取反 | 每一位 0 和 1 翻转 |
| `<<` | 左移 | 左边移出的位丢弃，右侧补 0 |
| `>>` | 算术右移 | 高位用原符号位补齐 |
| `>>>` | 逻辑右移 | 高位补 0 |

例如 `9` 是二进制 `1001`，`3` 是 `0011`，于是 `9 & 3` 的低位结果为 `0001`，也就是 1。Java 的 `byte`、`short`、`char` 在位运算前会提升为 `int`，所以结果不一定还是原来的小类型。位移也受整数位宽影响，初学阶段不建议拿它替代普通乘除法。

## 5. 流程控制：选择和重复

### 5.1 代码块与作用域

花括号 `{}` 内的一组语句称为代码块。代码块会影响局部变量的可见范围：变量通常只能在声明它的代码块及其内部使用。

```java
int outer = 1;
{
    int inner = 2;
    System.out.println(outer); // 可以访问外层变量
    System.out.println(inner);
}
// inner 在这里已经超出作用域，不能使用
```

### 5.2 `if`：根据条件选择

```java
if (条件) {
    // 条件为 true 时执行
} else {
    // 条件为 false 时执行
}
```

例如：

```java
int score = 85;
if (score >= 60) {
    System.out.println("及格");
} else {
    System.out.println("继续努力");
}
```

多个范围分支可以使用 `else if`：

```java
if (score >= 90) {
    System.out.println("优秀");
} else if (score >= 70) {
    System.out.println("良好");
} else if (score >= 60) {
    System.out.println("及格");
} else {
    System.out.println("需要补习");
}
```

条件从上到下依次判断；一旦某个分支成立，后面的分支就不再判断。即使只有一行代码，也建议保留花括号，能减少以后增删代码时的错误。

### 5.3 `switch`：按具体值分支

`switch` 适合根据一个值匹配多个具体选项；需要判断区间（例如分数段）时，通常用 `if-else`。

```java
char level = 'B';
switch (level) {
    case 'A':
        System.out.println("优秀");
        break;
    case 'B':
        System.out.println("良好");
        break;
    case 'C':
        System.out.println("继续努力");
        break;
    default:
        System.out.println("未知等级");
}
```

传统 `switch` 中，匹配后如果没有 `break`，程序可能继续执行后续分支，这叫贯穿（fall-through）。通常每个分支结束时写 `break`；`default` 处理其他情况。

### 5.4 新式 `switch` 表达式

较新的 Java 版本支持 `->` 写法；Java 14 起正式提供 switch 表达式：

```java
int score = 9;
char grade = switch (score) {
    case 10, 9 -> 'A';
    case 8 -> 'B';
    case 7, 6 -> 'C';
    default -> 'D';
};
```

这里的 `switch` 会产生一个值，赋给 `grade`，所以最后有分号。分支不会像传统写法那样意外贯穿。需要在某分支执行多条语句时，可以用代码块并以 `yield` 给出结果：

```java
char grade = switch (score) {
    case 9 -> 'A';
    case 8 -> 'B';
    case 7, 6 -> {
        System.out.println("成绩需要继续提升");
        yield 'C';
    }
    default -> 'D';
};
```

新语法需要足够新的 JDK；课程或项目使用较旧版本时，选择传统 `switch`。

### 5.5 `for`：次数大致明确时重复

```java
for (初始化; 继续条件; 每轮后的操作) {
    // 循环体
}
```

执行顺序是：初始化一次 → 判断条件 → 执行循环体 → 执行每轮后的操作 → 再判断。

```java
for (int i = 0; i < 3; i++) {
    System.out.println("第 " + i + " 轮");
}
```

`i` 从 0 开始，条件是 `i < 3`，所以循环体在 `i` 为 0、1、2 时执行，共 3 次。`i` 在 `for` 语句中声明，通常只能在这个循环的作用域内使用。

一个循环里可以再套一个循环。外层循环每运行一轮，内层循环会完整运行一次，所以两个各 3 次的循环通常会执行内层语句 3 × 3 = 9 次。

`for (;;)` 没有结束条件，通常会无限循环；如果确实需要无限循环，必须设计明确的退出方式，避免程序一直占用资源。

### 5.6 `while` 和 `do-while`

当循环结束时机由条件决定、次数不太确定时，`while` 常常更直观：

```java
int value = 100;
while (value > 0) {
    System.out.println(value);
    value /= 2;
}
```

`while` 会先判断条件，再决定要不要执行循环体，因此可能一次都不执行。

`do-while` 先执行一次循环体，再判断条件，因此至少执行一次。注意最后的分号：

```java
int i = 0;
do {
    System.out.println("至少执行一次");
    i++;
} while (i < 1);
```

### 5.7 `break` 和 `continue`

- `break`：结束当前所在的循环，跳到循环之后。
- `continue`：结束本轮循环，进入下一轮。

```java
for (int i = 0; i < 5; i++) {
    if (i == 2) {
        continue; // 不打印 2，继续下一轮
    }
    if (i == 4) {
        break;    // 到 4 时结束整个循环
    }
    System.out.println(i);
}
```

嵌套循环中，普通 `break` 和 `continue` 只影响离它最近的那一层循环。Java 允许给循环加标签并用 `break 标签名` 跳出外层循环，但入门阶段优先用清楚的条件和方法组织代码，少用标签跳转。

### 5.8 用调试器看懂循环

在 IDEA 代码行左侧点击可以设置**断点**。使用 Debug 启动后，程序到断点会暂停，可以查看变量当前值，并逐行执行。看 `for` 循环时观察 `i` 如何变化，通常比只读文字更容易理解。

## 6. JShell：快速试一小段代码

Java 9 起提供了命令行交互工具 **JShell**。在终端输入 `jshell` 后，可以直接输入表达式或语句并查看结果；输入 `/exit` 退出。

```text
jshell> 1 + 2
$1 ==> 3
```

它适合快速验证简单表达式，不替代正式项目中的 `.java` 文件和 IDE。命令是否可用取决于安装的 JDK 是否包含 JShell。

### 练习一：三位水仙花数

三位水仙花数等于各位数字的立方和。例如 `153 = 1³ + 5³ + 3³`。尝试打印所有三位水仙花数。

思路：遍历 100 到 999；用 `% 10` 取个位，用 `/ 10 % 10` 取十位，用 `/ 100` 取百位；比较三次方之和与原数。

```java
package test;

public class NarcissisticNumber {

    public static void main(String[] args) {
        int i = 100;
        while (i < 1000) {
            int a = i % 10;
            int b = i / 10 % 10;
            int c = i / 100;
            boolean result = a * a * a + b * b * b + c * c * c == i;
            if (result) {
                System.out.println("水仙花数：" + i);
            }
            i++;
        }
    }
}
```

### 练习二：九九乘法表

用两层 `for` 循环打印 1×1 到 9×9。外层控制行，内层控制当前行要打印到的列。想一想为什么内层条件可以写成 `j <= i`。

```java
package test;

public class MultiplicationTable {
    public static void main(String[] args) {
        for (int i = 1; i <= 9; i++) {
            for (int j = 1; j <= i; j++) {
                System.out.print(j + " * " + i + " = " + i * j + "\t");
            }
            System.out.println();
        }
    }
}
```

### 练习三：斐波那契数列

数列从 `1, 1, 2, 3, 5, 8, ...` 开始，每一项是前两项之和。写程序计算第 n 项，并先说明 n 从 1 还是从 0 开始编号，避免 off-by-one（差一位）错误。数列增长很快，大 n 可能超出 `int` 的范围。

```java
package test;

import java.util.Scanner;

public class Fibonacci {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        System.out.print("请输入您想获取第几个斐波那契数：");
        int target = sc.nextInt();
        int a = 1, b = 1, result;
        switch (target) {
            case 1 -> System.out.println("斐波那契数列第" + target + "个数为：" + a);
            case 2 -> System.out.println("斐波那契数列第" + target + "个数为：" + b);
            default -> {
                for (int i = 2; i < target; i++) {
                    result = a + b;
                    a = b;
                    b = result;
                    if (i == target - 1) {
                        System.out.println("斐波那契数列第" + target + "个数为：" + result);
                    }
                }
            }
        }
    }
}
```
